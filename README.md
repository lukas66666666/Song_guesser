<h1>Verse</h1>
A web app that finds a song just by a part of the lyrics.

Try it <a href="https://song-guesser-rho.vercel.app">here</a><br>
<h2>Features:</h2>
<ul>
  <li>Find a song from lyrics</li>
  <li>Get top 10 results</li>
  <li>Play the songs to find the correct one</li>
</ul>
<h2>How it works</h2>
The app is using Genius API to find the song from the lyrics, then the song info is send to iTunes to get the song preview.
<h2>Built with:</h2>
  <ul>
    <li>Vercel</li>
    <li>Genius API</li>
    <li>iTunes API</li>
    <li>vanilla JS/HTML/CSS</li>
  </ul>
